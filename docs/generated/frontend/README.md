### Применение в проекте

Все элементы из этих спецификаций интегрированы в:
- **[UI Kit / Design System](../../UI-Kit-Design-System.md)** - Основная дизайн-система проекта «Эмоциональный баланс»
- **[Image Generation Prompts](../../design-system/Image-Generation-Prompts.md)** - Промпты для создания всей графики

### Адаптация референса

Спецификации Q Psychology служат **референсом и вдохновением**, но адаптированы под:
- Теплую, эмпатичную палитру (sage green, warm sand, coral)
- Тон «эмоциональной поддержки» (не клиническую строгость)
- Требования из [PRD](../../PRD.md) и [Vision](../../Vision-Product-brief.md)
