## 4) Детальная спецификация разделов

### 4.1 📊 Дашборд (главная админки)

**URL:** `/admin/`

**Цель:** Быстрый обзор ключевых метрик за сегодня/неделю/месяц.

**Виджеты (карточки):**

1. **Воронка записи (booking funnel)**
   - Метрики: `booking_start`, `booking_slot_selected`, `booking_paid`, `booking_confirmed`
   - Период: сегодня / 7 дней / 30 дней
   - Конверсия по каждому шагу

2. **Telegram**
   - Новые подписки: `tg_subscribe_confirmed`
   - Активные пользователи: `tg_interaction` (уникальные за период)
   - Stop rate: `tg_series_stopped`

3. **Интерактивы**
   - Старты/завершения топ-3 интерактивов
   - Completion rate

4. **Встречи**
   - Предстоящие встречи (список 5 ближайших)
   - No-show rate за последние 30 дней
   - Завершённые встречи за период

5. **Модерация**
   - Очередь модерации (кол-во pending)
   - Средне время модерации за неделю
   - Алерт, если время >24 часа

6. **Выручка**
   - GMV за период
   - AOV
   - Рост/падение к прошлому периоду

**Действия:**
- Фильтр по периоду (сегодня / 7д / 30д / custom)
- Кнопки быстрого перехода в разделы

### 4.2 📅 Расписание (FR-ADM-2)

**URL:** `/admin/schedule/`

**Цель:** Управление слотами, исключениями, буферами.

#### 4.2.1 Виды экранов

**A) Календарь (день/неделя/месяц)**
- Визуальное представление слотов
- Цветовая кодировка:
  - 🟢 Доступен (свободный слот)
  - 🟡 Забронирован
  - 🔴 Исключение (отпуск/перерыв)
  - ⚪ Буфер (нет брони)
- Клик на слот → детали / редактирование

**B) Список слотов**
- Табличный вид (дата/время/услуга/статус)
- Фильтры: по услуге, по статусу, по дате
- Сортировка
- Массовые действия (удалить выбранные, экспорт)

**C) Настройки расписания**
- Правила повторения (weekly/biweekly/custom)
- Длительность по умолчанию (по услугам)
- Буферы между сессиями (минуты)
- Часовой пояс психолога
- Исключения (даты отпусков/праздников)

#### 4.2.2 Действия

**Создать слот:**
- Дата/время (локальное, автоконверсия в UTC)
- Услуга (выбор из списка или "любая")
- Повторение (одиночный / еженедельно / custom)
- До даты (если повторение)

**Редактировать слот:**
- Изменить время/услугу
- Отменить (с уведомлением клиенту, если забронирован)
- Добавить заметку (internal, не видна клиенту)

**Добавить исключение (отпуск/праздник):**
- Диапазон дат
- Причина (внутренняя заметка)
- Действие с существующими бронями (предложить перенос/отменить)

**Синхронизация с Google Calendar:**
- Импорт событий (блокировка слотов)
- Экспорт бронирований в календарь
- Настройка двусторонней синхронизации

### 4.3 💼 Услуги (FR-ADM-2, research 08-* раздел 4)

**URL:** `/admin/services/`

**Цель:** Управление услугами, ценами, депозитами, правилами.

#### 4.3.1 Список услуг

Таблица:
- Название
- Формат (онлайн/офлайн/гибрид)
- Длительность
- Цена/депозит
- Статус (активна/черновик/архив)
- Действия (редактировать/дублировать/архивировать)

#### 4.3.2 Карточка услуги

**Основное:**
- Название (внутреннее и публичное)
- Slug (для URL)
- Описание (краткое и полное)
- "Для кого" (целевая аудитория)
- "Что будет" (процесс)
- Длительность (минуты)
- Формат (онлайн/офлайн/гибрид)
- Адрес (если офлайн): м. Черкизовская, детали

**Цены:**
- Цена (основная)
- Депозит (если применимо)
- Валюта (RUB)
- Скидки/пакеты (опционально)

**Правила бронирования:**
- Минимум времени до встречи (часы)
- Правила отмены (часы до встречи / возврат депозита)
- Правила переноса (кол-во раз / сроки)

**Анкета:**
- Выбор шаблона анкеты (или custom)
- Обязательные поля

**Публикация:**
- Статус (черновик/опубликована/архив)
- Видимость на сайте (да/нет)
- Порядок в списке

**Аудит:**
- История изменений цен/правил (кто/когда/старое/новое)

#### 4.3.3 Действия

- Создать услугу (мастер)
- Редактировать
- Дублировать (для создания вариации)
- Архивировать (скрыть, но сохранить историю)

### 4.4 📝 Контент (FR-ADM-3)

**URL:** `/admin/content/`

**Цель:** Управление статьями, ресурсами, лендингами тем, служебными страницами.

#### 4.4.1 Типы контента

**A) Статьи (`/blog/{slug}/`)**
**B) Ресурсы (`/resources/{slug}/`)** — упражнения/аудио/чек-листы
**C) Лендинги тем (`/s-chem-ya-pomogayu/{topic-slug}/`)**
**D) Служебные страницы** — "О психологе", "Как проходит", FAQ

#### 4.4.2 Список контента

Табличный вид:
- Тип
- Название
- Автор
- Статус (черновик/на модерации/опубликовано/архив)
- Дата публикации
- Просмотры (за 30д)
- CTA rate
- Действия

Фильтры:
- По типу
- По статусу
- По теме/тегам
- По автору

Сортировка:
- По дате (новые/старые)
- По популярности (просмотры)
- По конверсии (CTA rate)

#### 4.4.3 Редактор контента

**Основное:**
- Название (H1)
- Slug (для URL, автогенерация с редактированием)
- Тип контента (статья/ресурс/лендинг)
- Автор (выбор или текущий пользователь)

**Содержание:**
- WYSIWYG-редактор (markdown или rich text)
- Блоки:
  - Текст
  - Изображение (из медиа-библиотеки)
  - Видео/аудио (embed или загрузка)
  - Цитата
  - Призыв к действию (CTA)
  - "Попробовать сейчас" (ссылка на интерактив/ресурс)
  - Дисклеймер
  - FAQ (аккордеон)

**Метаданные:**
- Краткое описание (для карточек/SEO)
- Featured image (обложка)
- Темы/теги (множественный выбор)
- Формат (`article|note|resource|audio|checklist`)
- Time-to-benefit (`1_3_min|7_10_min|20_30_min`)
- Support level (`self_help|micro_support|consultation`)

**SEO:**
- Meta title
- Meta description
- Keywords (теги)
- Canonical URL (если нужно)

**Перелинковка (автоподсказки):**
- Связанные статьи (рекомендации на основе тем)
- Связанные интерактивы
- Связанные услуги

**QA-чеклист перед публикацией (FR-ADM-3):**
- [ ] Есть дисклеймер "не диагноз/не лечим/не гарантии"
- [ ] Тон бережный, не директивный
- [ ] Есть блок "попробовать сейчас" (упражнение/ресурс)
- [ ] Есть CTA (Telegram/запись) с объяснением
- [ ] Внутренняя перелинковка (минимум 3 ссылки)
- [ ] Изображения с alt-текстами
- [ ] Проверка орфографии

**Публикация:**
- Статус (черновик/на модерации/опубликовано)
- Дата публикации (сейчас/запланировать)
- Видимость (публичная/только по ссылке)

**Версионирование:**
- История изменений (кто/когда/diff)
- Откат к предыдущей версии

#### 4.4.4 Медиа-библиотека (FR-ADM-12)

**URL:** `/admin/content/media/`

**Функции:**
- Загрузка файлов (drag & drop или выбор)
- Типы: изображения (jpg/png/webp), аудио (mp3/wav), PDF
- Организация:
  - Папки (по типу/теме)
  - Теги
  - Поиск по названию/тегам
- Превью
- Метаданные:
  - Название
  - Alt-текст (для изображений)
  - Описание
  - Размер/разрешение
  - Дата загрузки
- Действия:
  - Редактировать метаданные
  - Скопировать URL
  - Удалить (с подтверждением, если используется в контенте)

### 4.5 🎮 Интерактивы (FR-ADM-6)

**URL:** `/admin/interactive/`

**Цель:** Управление текстами, параметрами, порогами интерактивов без кода.

#### 4.5.1 Список интерактивов

Карточки/таблица:
- Тип (квиз/навигатор/термометр/скрипты/ритуал)
- Название
- Тема (topic)
- Статус (активен/черновик/архив)
- Статистика за 30д:
  - Старты
  - Completion rate
  - CTA rate
- Действия (редактировать/дублировать/превью)

Группировка по типам:
- **Квизы/мини-диагностики** (QZ-01, QZ-02, QZ-03...)
- **Навигатор состояния** (NAV-01)
- **Термометр ресурса** (TRM-01)
- **Скрипты границ** (BND-01)
- **Подготовка к консультации** (PRP-01)
- **Мини-ритуалы** (RIT-01..10)

#### 4.5.2 Редактор квиза (QZ-*)

**Основное:**
- Название (внутреннее и публичное)
- Slug
- Тема (topic): `anxiety|burnout|stress|relationships|sleep`
- Описание (для карточки)
- Время прохождения (минуты)

**Вопросы:**
Список вопросов (drag & drop для сортировки):
- Текст вопроса
- Тип ответа:
  - Шкала (0..3, 0..4, 0..10)
  - Выбор (single/multiple)
- Варианты ответов (для выбора)
- Вес/балл (для подсчёта)

**Пороги результатов:**
- **Низкий (low)**: от X до Y баллов
- **Умеренный (moderate)**: от Y до Z баллов
- **Высокий (high)**: от Z баллов

**Результаты (по уровням):**
Для каждого уровня (low/moderate/high):
- Заголовок
- Описание/расшифровка
- Шаги "сейчас" (2-3 пункта, markdown)
- Шаги "на неделю" (2-3 пункта)
- Блок "когда стоит обратиться к специалисту"
- CTA (Telegram/запись, настройка текстов кнопок)

**Дисклеймеры:**
- Текст на старте ("не диагноз, не экстренная помощь")
- Текст на результате

**Кризисный режим:**
- Порог для автоматического показа экстренной помощи (балл или вопрос-триггер)
- Текст блока экстренной помощи (можно переопределить дефолтный)

**Публикация:**
- Статус (черновик/опубликован)
- Превью (открыть в новой вкладке, как видит пользователь)

#### 4.5.3 Редактор навигатора состояния (NAV-01)

**Структура:**
Древо шагов (визуальный редактор):
- Шаг 0 (старт): выбор "что сейчас ближе" (3-4 карточки)
- Шаги 1..10: бинарные/тернарные выборы
- Финал: профили результатов

**Каждый шаг:**
- Номер шага
- Текст вопроса/выбора
- Варианты ответов (карточки):
  - Текст карточки
  - Следующий шаг (связь)
- Кризисный триггер (опционально)

**Профили результатов:**
- ID профиля: `stabilize_now|restore_energy|boundaries|clarify|support_contact`
- Название
- Описание
- Шаги "сейчас" (2-3)
- Шаги "на неделю" (2-3)
- Блок "когда обратиться"

#### 4.5.4 Редактор термометра ресурса (TRM-01)

**Вопросы:**
- Энергия (шкала/якоря)
- Напряжение (шкала/якоря)
- Поддержка (шкала/якоря)
- Сон (выбор)
- Что съедает энергию (выбор)

**Формула:**
- Правило расчёта `resource_level` (low/moderate/high)
- Можно настроить веса

**Результаты (по уровням):**
- Аналогично квизам

#### 4.5.5 Редактор скриптов границ (BND-01)

**Сценарии:**
Список сценариев (работа/семья/партнёр/друзья):
- Название
- Описание

**Стили:**
- Мягко
- Коротко
- Твёрдо

**Цели:**
- Отказать
- Попросить о помощи
- Обозначить правило
- Взять паузу

**Варианты фраз (матрица):**
Для каждой комбинации (сценарий × стиль × цель):
- 3-6 вариантов фраз (текстовое поле)
- ID варианта (для аналитики)

**Блок безопасности:**
- Текст блока "что делать, если давят"
- Триггеры небезопасности (если сценарий связан с насилием)

#### 4.5.6 Библиотека мини-ритуалов (RIT-*)

**Список ритуалов:**
Карточки:
- ID (RIT-01..10)
- Название
- Тема (topic)
- Длительность (минуты)
- Описание "зачем"
- Статус (активен/черновик)

**Карточка ритуала:**
- Название
- Slug
- Тема
- Длительность
- "Зачем" (1 предложение)
- Инструкция (пошаговая, markdown):
  - Шаг 1
  - Шаг 2
  - ...
- Аудио (опционально, из медиа-библиотеки)
- Таймер (да/нет)
- Дисклеймер "если стало хуже — остановитесь"

**Действия:**
- Добавить новый ритуал
- Редактировать
- Дублировать
- Архивировать

#### 4.6.1 Список подборок

#### 4.6.2 Редактор подборки

- Slug

- `approved` — одобрен, ждёт ответа (для вопросов)

- По дате

**Сортировка:**
- По дате (старые первыми, для SLA)
- По приоритету (кризисные первыми)

#### 4.10.2 Карточка модерации (анонимный вопрос)

**URL:** `/admin/moderation/questions/{question_id}/`

**Основное:**
- Дата/время отправки
- Статус
- Триггеры автофильтра (если есть)

**Содержание:**
- Текст вопроса (полный)
- Маркировка PII (если автофильтр нашёл)
- Контакт пользователя (если оставил)

**Чеклист модерации (из UGC-Moderation-Rules.md раздел 3.2.2):**
- [ ] Безопасность: нет кризисных маркеров
- [ ] Этика: не требует медицинских назначений/диагноза
- [ ] PII: нет личных данных (или маскированы)
- [ ] Границы: не просит "терапию в комментариях"
- [ ] Scope: в рамках компетенции психолога

**Действия:**
- **Одобрить** (owner отвечает позже)
- **Отклонить** с причиной:
  - Кризис (отправить шаблон "экстренная помощь")
  - Медицинский/диагноз (шаблон "out-of-scope")
  - Терапия в комментариях (шаблон "приглашение на консультацию")
  - Спам/реклама (удалить без ответа)
- **Эскалировать к owner** (если сложный случай)
- **Редактировать текст вопроса** (маскировать PII) → одобрить

**Шаблоны ответов (из UGC-Moderation-Rules.md раздел 5):**
- Кризис (высокий риск)
- Медицинский вопрос (out-of-scope)
- Запрос "терапии в комментариях"
- Общий безопасный ответ

**Ответ психолога (если approved):**
- Текстовое поле (markdown)
- Кнопка "Опубликовать ответ"

**История:**
- Кто/когда модерировал
- Кто/когда ответил
- Изменения статуса

#### 4.10.3 Дашборд модерации (метрики из UGC-Moderation-Rules.md раздел 8)

**URL:** `/admin/moderation/dashboard/`

**Метрики:**

| Метрика | Цель | Формула |
|---|---|---|
| **Время модерации** | <24 часа (обычные), <4 часа (кризис) | Timestamp submit → approve/reject |
| **Доля отклонённых** | <10% | rejected / total |
| **Доля кризисных** | Следить за динамикой | flagged_crisis / total |
| **Жалобы на модерацию** | 0 (в идеале) | Ручной учёт |

**Графики:**
- Динамика очереди модерации (по дням/неделям)
- Время модерации (гистограмма)
- Доля статусов (pie chart)
- Доля триггеров

**Алерты:**
- ⚠️ Очередь >10 вопросов
- ⚠️ Кризисный вопрос >4 часа без модерации
- ⚠️ Среднее время модерации >24 часа

## 5) Технические требования

### 5.1 Производительность

- Загрузка дашборда: <2 секунды
- Загрузка списка (контент/лиды): <1 секунда
- Редактор: автосохранение каждые 30 секунд
- Аналитика: кэширование тяжёлых запросов (TTL 5-15 минут)

### 5.2 Безопасность

- HTTPS везде
- RBAC (role-based access control)
- CSRF protection
- XSS protection
- SQL injection prevention
- Rate limiting (API)
- Аудит-лог критичных действий

### 5.3 Доступность (базовая)

- Клавиатурная навигация
- Семантический HTML
- ARIA-атрибуты для интерактивных элементов
- Контраст WCAG AA (минимум)

### 5.4 Совместимость

- Браузеры: последние 2 версии Chrome/Firefox/Safari/Edge
- Разрешение: минимум 1280×720 (desktop)
- Мобильная версия: не обязательна для релиза 1 (админка — desktop-first)

## 7) User Stories для тестирования

### US-ADM-INT-01: Редактировать квиз без кода
- **Как** owner, **я хочу** изменить тексты вопросов и порог "высокого" уровня в квизе QZ-01, **чтобы** адаптировать интерактив без разработчика.
- **AC**: я открываю редактор квиза, меняю текст вопроса 3 и порог с 10 на 9, сохраняю, открываю превью — вижу изменения.

### US-ADM-MOD-01: Модерировать анонимный вопрос за <24 часа
- **Как** assistant, **я хочу** обработать анонимный вопрос в течение 24 часов, **чтобы** соблюдать SLA.
- **AC**: я открываю очередь модерации, вижу вопрос со временем "18 часов в очереди", проверяю чеклист, одобряю, owner получает уведомление.

### US-ADM-NO-SHOW-01: Отметить исход встречи
- **Как** owner, **я хочу** отметить, что клиент не пришёл на встречу, **чтобы** метрика no-show была корректной.
- **AC**: я открываю список предстоящих встреч, нахожу завершённую встречу, нажимаю "Отметить исход", выбираю "Не явился", опционально указываю причину, сохраняю. В дашборде no-show rate обновляется.

### US-ADM-EVENT-01: Создать мероприятие и отправить напоминания
- **Как** owner, **я хочу** создать вебинар, получить регистрации и отправить напоминания, **чтобы** участники не забыли.
- **AC**: я создаю мероприятие (дата/время/формат), публикую лендинг, получаю 10 регистраций, за 24ч система автоматически отправляет напоминания (или я отправляю вручную).

### US-ADM-MEDIA-01: Загрузить изображение и использовать в статье
- **Как** editor, **я хочу** загрузить изображение в медиа-библиотеку и вставить в статью, **чтобы** не хранить файлы локально.
- **AC**: я открываю медиа-библиотеку, загружаю файл, добавляю alt-текст, копирую URL, вставляю в редактор статьи, сохраняю, публикую — изображение отображается.
